# EmDash shift checklists

The free Restaurant Opening & Closing Checklists plugin lets an EmDash administrator create reusable checklists for locations and shifts. It runs on the EmDash site and does not require a TenorOps account.

Install the plugin from the EmDash registry, then open **Shift checklists** in the admin navigation. Only users who can manage plugins in EmDash can use the plugin's checklists. A site administrator may need to install the plugin or grant access.

Create a blank checklist or start from an opening or closing template. Enter a name and location, choose a shift, and add one task per line. Edit a checklist as your procedures change. The templates are examples; your team is responsible for choosing tasks that suit your operation and local requirements.

If another administrator saves changes while you are editing the same checklist, your save is rejected. Open the checklist again to review the latest version before making your changes.

Start a shift from a checklist, mark tasks complete as work is done, and reopen a task if needed. Complete the shift when finished; unfinished tasks remain visible in its history. Each shift keeps a copy of the checklist as it was when the shift started, so later edits do not change past records. Archive a checklist to stop using it for new shifts; its existing shifts remain in history.

Checklist and shift records are stored on your EmDash site. The plugin does not send them to TenorOps. The website operator is responsible for its site's backups and access to those records.
